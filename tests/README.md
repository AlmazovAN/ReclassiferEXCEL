# Локальные проверки ReclassifierEXCEL

Основной способ: `powershell -NoProfile -ExecutionPolicy Bypass -File tools/local-ci.ps1 verify`.

Проверяем:
- корректность списка зависимостей Worker и отсутствие отсутствующих файлов;
- сборку `dist/ReclassifierEXCEL.html`;
- управление папками и импорт;
- безопасную запись двух накопительных Excel;
- потоковый сценарий МБ и предотвращение повторного добавления строк;
- работу журнала и его экспорт;
- независимые правила и инженерные ограничения реклассификации V4.

Тестовые файлы должны быть синтетическими. Запуск тестов не должен открывать рабочие корпоративные книги и не должен обращаться к GitHub.
