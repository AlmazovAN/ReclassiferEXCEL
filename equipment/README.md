# Equipment — рабочий контракт «Папок»

Рабочая сборка распознаёт четыре исходных каталога:
- `CatalogMountedEquipment` — навесное оборудование;
- `CatalogStationaryEquipment` — стационарное оборудование;
- `CatalogTransport` — транспорт;
- `CatalogZabbixEquipmentTree` — дерево мониторинга.

Производный `Equipment_Combined` формируется по `src/folders/engine/modules/equipment/equipment_logic.js` и `equipment_config.js`; независимо загружаемым источником истины не является.

Обновление исходных наборов выполняется через проверенный набор справочников и существующую логику формирования Combined. Идентификаторы оборудования и разделение по `unit` не должны теряться при частичном обновлении.

В GitHub не должны храниться реальные каталоги. Проверяйте актуальные поля в `equipment_config.js`; прямое изменение под рабочие Excel без проверки контракта запрещено.
