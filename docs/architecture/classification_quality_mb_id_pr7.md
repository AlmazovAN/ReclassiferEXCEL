# PR 7 — сверка ID ITSM Сириус ↔ МБ и диагностика инициаторов

## Принятое правило
Для показателя «Качество классификации ЦГПС» используется только наличие
нормализованного номера ITSM Сириус (`itsm_data.number`) среди полей
`mobile_brigade_data.request` **текущего загруженного Dataset МБ**.
Проверка даты создания обращения и дат покрытия/свежести МБ
**не применяется**. Дата выполнения (иначе закрытия) сохраняется
отдельно как основание выбора отчётного месяца.

| Состояние | Что означает | Влияние на KPI ЦГПС |
| --- | --- | --- |
| «Есть в МБ» | Есть хотя бы одна задача с данным номером ITSM | Учитывать при выполнении условий A/B/C/D |
| «Нет в МБ» | Номер ITSM отсутствует в **загруженном Dataset МБ** | Исключить, счётчик `excludedNoMbCount` |
| «Нет данных МБ» | Dataset МБ отсутствует/недоступен | Для затронутого периода `no-data / mb-coverage-unknown` |
| Нет номера ITSM | Номер отсутствует или пуст после нормализации | Исключить, счётчик `excludedMissingRequestCount` |

Несколько задач МБ с одним номером обращения не умножают количество
обращений. Сохранённая в ITSM колонка `mbPresence` остаётся
историческим снимком для просмотра; расчет берёт живой текущий набор МБ.

**Ограничение:** отсутствие ID в неполной выгрузке МБ не доказывает,
что такого обращения нет в корпоративной системе. Полноту выгрузки
нужно обеспечить организационно: набор должен соответствовать
проверяемому периоду и подразделениям. Программа не делает
заключение о полноте на основании дат.

## Инициаторы
- A/B/C («INC …»): группа инициаторов **не ограничивает** показатель.
- D («RITM вместо INC»): только точно установленная группа
  `initiatorGroup = «ЦГПС»` входит в KPI.
- Другая **непустая** группа → отдельный
  `excludedOtherInitiatorRitmCount`.
- Пустая/неустановленная группа в обработанном ITSM → отдельно
  `excludedUnknownInitiatorRitmCount`. Это **не ЦГПС**.
- Пустые номера ITSM → `excludedMissingRequestCount`, без
  притворного «Нет в МБ».
- Все исключённые RITM категории D, независимо от группы инициаторов,
  продолжают входить в **общий показатель качества классификации**.

## Изменения
- `src/js/modules/itsm/mb_presence.js`: API для Worker и KPI сохранён,
  но аргументы даты/покрытия не влияют на результат.
- `src/js/kpi/preparation/classification.js`: новый раздельный учёт
  групп и пустых номеров, ID-only сопоставление.
- `src/js/kpi/calculator/classification_quality_cgps/calculate.js`:
  два новых компонента и выбранная диагностика без изменения формулы.
- Графики, карточка дашборда, технический контракт, паспорт и PDF
  отображают уточнённые значения.
- Технические описания предыдущих PR обновлены.
- Регрессионные тесты изменены в соответствии с правилами.

## Что не изменено
Общая формула `A/(A+B+C+D)×100`, формула ЦГПС
`A_МБ/(A_МБ+B_МБ+C_МБ+D_ЦГПС,МБ)×100`,
методика расчётного месяца, выгрузка источников, схема SQLite и
все остальные KPI.
