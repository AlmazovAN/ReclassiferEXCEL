# Шаг 9/9 — расширяемый Forecast Engine

## Политика
- Горизонт **1 календарный месяц** по умолчанию.
- Метод `linear-trend` (обычная линейная регрессия по времени) с отдельной конфигурацией для каждого KPI в `OVERRIDES` файла `src/js/kpi/forecast_engine.js`.
- Дополнительный локальный метод `last-value`, пригодный как самостоятельная модель для выбранного KPI и как обязательный benchmark.
- Метод и версия возвращаются вместе с прогнозом; изменение метода одного KPI не затрагивает другие и не меняет Calculator.
- Требуется минимум 6 непрерывных месячных точек, плюс минимум 2 исторических контрольных прогноза. В каждом контрольном прогнозе используются только более ранние данные (walk-forward, без заглядывания в будущее).
- Для модели и naive baseline вычисляется MAE. Если MAE линейного тренда выше MAE baseline, значение не показывается (`worse-than-naive-baseline`).
- Пропуски, нечисловые точки, отсутствие актуального месяца и недоступная история дают `null` и объяснимую причину.
- Проценты ограничены [0,100], абсолютные значения снизу ограничены нулём; `bounded` отражает применение ограничения.
- Исторический ВБР без исторического парка оборудования остаётся недоступен. Неподключённые KPI не прогнозируются.
- В паспорте KPI показаны метод, версия, горизонт, MAE модели и baseline, причина отклонения.

## Расширение
В `OVERRIDES` можно задать `sla:{methodId:'last-value'}`, а для новых методов добавить адаптер `predict(history,horizon)` в `adapters`. Потребители читают унифицированный Forecast Result из `kpiView.cards[id].forecast`.

`externalAdapter` документирует будущий контракт корпоративного ML/AutoML API: `kpiId,history,horizonMonths,modelVersion,sourceRevisions` на входе и `value,methodId,methodVersion,quality,horizon` на выходе. **Сетевые вызовы, адреса, секреты и подключение API не реализованы.** Офлайн-сборка остаётся автономной. Внешняя модель до интеграции явно возвращает `forecast-method-not-connected`.

## Границы
Линейный прогноз — прототипная оценка, не утверждённая официальная методика. Backtest на нескольких месяцах не гарантирует будущую точность. Нет синтетических значений и автозаполнения пропусков. Результаты не влияют на официальные KPI Results, формулы, Dataset, SQLite или PDF.

## Проверки
`tests/test_kpi_forecast_engine.js`: горизонт 1 месяц, тренд, ограничение процентов, отсутствие истории, ВБР, конфигурация конкретного KPI, заглушка ML API и проигрыш baseline. Полная регрессия, монолитный HTML и офлайн Chromium — GitHub Actions.
