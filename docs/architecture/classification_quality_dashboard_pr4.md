# PR 4 — отображение качества классификации в отчёте

## Назначение
Отобразить в разделе «Данные и качество» два независимо рассчитанных
показателя: **«Качество классификации — общее»** и
**«Качество классификации ЦГПС»**. Оба расчёта поставляются
KPI Calculator и текущим Report Snapshot, а не вычисляются в интерфейсе.

Общее качество показывает, насколько первоначальная классификация
обращений ITSM Сириус соответствует результату инженерной проверки
по текстовому описанию фактической неисправности и выполненной работы.
Качество ЦГПС использует только обращения, по которым зарегистрированы
работы в МБ **в рамках деятельности ЦГПС**. Для INC категория и
инициатор не ограничиваются, а «RITM вместо INC» учитывается
только при группе инициаторов «ЦГПС».

## Карточки
- Первая: `classification_quality` (источник ITSM Сириус).
- Вторая: `classification_quality_cgps` (ITSM Сириус + актуальный МБ).
- Обе отражают выбранные фильтры периода, рудника и класса оборудования;
  предыдущий месяц и прогноз берутся из существующего View Model.
- При `mb-coverage-unknown` у ЦГПС вместо вымышленного процента отображается
  «Нет данных» с пояснением. «Нет в МБ» — другое состояние: достоверно
  отсутствующие заявки исключаются из формулы ЦГПС.

## Графики
- В разделе «Данные и качество» отображается месячное сравнение двух
  независимых значений на одной процентной шкале 0–100.
- Используется `snapshot.series.monthly`; периоды без достоверного
  значения сохраняются как разрывы линии, а не соединяются или замещаются нулём.
- Кнопка «График» на каждой карточке открывает действующий универсальный
  график с выбором до трёх рудников, стационарного/навесного оборудования,
  наименования аналитического оборудования, периода и скользящего тренда.
- Наименования для классификации берутся из соответствующей подготовленной
  таблицы KPI; `equipmentName` здесь — аналитическая группировка, а
  не ITSM-колонка «НаименованиеТехники».
- В детализации выбранного ряда и месяца выводятся категории A/B/C/D,
  числитель, знаменатель и результат. Для ЦГПС дополнительно показываются
  «Нет в МБ», «Нет данных МБ» и «RITM других инициаторов» с объяснением.
- Если итог ЦГПС недоступен, составляющие остаются доступными для диагностики,
  но процент не подменяется значением для неполной выборки.

## Границы
- PR 4 — только отображение и маршрутизация существующих KPI; никаких
  новых методологических формул или изменений исходных Dataset.
- Методика и паспорта сохраняют прежнюю структуру ВБР/КТГ.
- Экспорт PDF отдельно дорабатывается в согласованном последующем PR,
  не является предметом этого изменения.
- Контроль: два видимых показателя, сравнение с разрывами, компоненты,
  фильтры, доступность, работа без сети и отсутствие регрессий ВБР/КТГ.
