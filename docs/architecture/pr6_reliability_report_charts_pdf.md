# PR6 — отчет надёжности СДГР: комплектность, графики и PDF

## Цель
Повысить проверяемость управленческого отчёта, не меняя расчёт KPI, состав Dashboard Dataset, структуру SQLite или логику прогнозирования.

## Единый исходный снимок
WEB и PDF используют один существующий неизменяемый `reliability-report` Report Snapshot. Общая презентационная проекция `ReclassifierReliabilityPresentation` считает только:

- количество рассчитанных KPI с `dataState=available` (не интерпретирует `0` как отсутствие);
- доступных / всех источников;
- число месяцев с данными в Snapshot;
- временные ряды с **явным null** в месяцы, для которых KPI недоступен.

Примечание: «месяцев истории» — количество строк `snapshot.series.monthly`, не число месяцев с доступным конкретным KPI; каждый график отдельно показывает «фактические значения N из M».

## Графики
Сглаживание, интерполяция, добавление нулей и удаление месяцев запрещены. При пропуске данных линия ВБР или SLA прерывается. Сохраняются фиксированные позиции месяцев и доступные фактические точки; при одном или нуле доступных значений отображается причина отсутствия линии. При большом периоде месячные подписи показываются с разреживанием, а не накладываются друг на друга. Прогнозное значение ВБР остаётся пунктиром с отдельным текстом «прогноз, не факт» и не подменяет основной результат KPI.

## PDF
Версия PDF Renderer — **1.2.0**. В титульной части есть такой же блок комплектности. Имя и fingerprint PDF учитывают не только сами KPI, диагностические показатели и классификацию, но также *исторические месячные ряды ВБР и SLA*. Изменение истории не оставляет старое имя PDF при неизменном KPI за текущий месяц.

PDF создаётся только из выбранного Snapshot; предварительная стадия `primary` не может экспортироваться как готовый отчёт. Файл по-прежнему создаётся полностью офлайн через canvas/JPEG и сборку PDF 1.4, без внешних библиотек и сетевых запросов.

При выгрузке показывается процент **успешно закодированных страниц** (до 95%), затем 100% после сборки PDF. Это не предсказание времени окончания. Завершение старой выгрузки не меняет состояние панели, если пользователь уже выбрал другой срез.
