# PR9 — заключительная ревизия серии 0.35.x

## Основание
Первоначальный план из восьми PR: CI и главная; глобальные состояния; ITSM/МБ и даты; автоматический KPI; SQLite-кэш; дашборд/PDF; управление проблемами; паспорта KPI/справочники/очистка.

## Подтверждено исходниками и GitHub
- PR1–PR8 объединены с main; PR7 = #272, PR8 = #274.
- PR7: три новых KPI количества/доли задач и уникальных PRB с работами; восемь **диаграмм связей и человеко-часов**, а не восемь согласованных исходных числовых показателей стадий управления проблемами.
- PR8: упрощён каталог паспортов, классификатор отказов доступен из «Справочников», исходный маршрут сохранён.
- VERSION перед PR9 = 0.35.0. Версионирование/релиз после merge проверяется отдельно на main.
- Основные методики KPI, SQLite v5 и расчетные цепочки не изменяются данным PR.

## Существенное расхождение, не скрывать косметической приёмкой
Первоначальная постановка PR7 содержала восемь количественных показателей: 4 счётчика АВР ITSM/МБ и 4 счётчика PRB/этапов. Реализованный PR7 описывает восемь иных диаграмм. Доступные ITSM/МБ связи не доказывают статусы поиска причины, согласования мероприятий и подтверждения эффекта.
**Решение:** методически не подменять отсутствующие признаки приближёнными оценками. Требуется отдельный аналитический PR после утверждения определений, источников и эталонов.

## Регрессионные условия
1. Отдельная страница KPI выводит паспорт из единого каталога; поиск, фильтры, счетчики не возвращаются.
2. Не подключённые методики остаются доступны.
3. «Справочники» открывают классификатор с прежними операциями; прямой маршрут остаётся рабочим.
4. CORE, FULL, SQLite, офлайн Chromium и PDF проходят штатную CI-цепочку.
5. Показатели PR7 и первоначальные расчётные формулы не изменяются.

## Отложено сознательно
- Разработка новых методов расчёта стадий PRB, т.к. источники не позволяют подтвердить эти признаки.
- Заявление о полном соответствии корпоративной SQLite без реального файла.
- Механическое удаление общих стилей без доказательства неиспользования в CORE/FULL/PDF.
