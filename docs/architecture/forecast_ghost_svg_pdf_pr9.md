# PR 9 — Прогнозная «призрачная» точка SVG и PDF

## Методическая граница

PR8 разрешает **экспериментальный прогноз завершения текущего, ещё открытого календарного месяца** по компонентам ВБР и КТГ. Это **не** прогноз следующего месяца и не фактическая величина. PR9 только визуализирует этот результат. В формулах Calculator, правилах классификации, истории, источниках и Snapshot KPI Result изменений нет.

Синхронная модель PR8: `forecastType=current-month-nowcast`, `methodId=monthly-components-remaining-days`, `dataState=available`, `horizon=текущий месяц`, `observedValue`, `projectedComponents`, `quality`, `caveats`. В сценариях недостаточности вместо поддельного числа возвращаются `value=null` и `reason`.

## Подробные SVG-графики

- При открытии модального окна оригинальный Report Service вычисляет **отдельный** прогноз для каждой фактически отображаемой пары `рудник × класс оборудования` с теми же параметрами `equipmentName`, что и обычный месячный ряд. Это исключает ошибку использования общешахтного прогноза для отдельного рудника или класса.
- Существующий `chartResultPoint` из Calculator и его `value` остаются неизменными. История продолжает обрабатываться обычным `Chart View Model`; для прогноза используются только полученные числители/длительности и признак неполного наблюдения. Никакого среднего арифметического KPI.
- **Горизонт — тот же месяц:** вертикальный пунктир из наблюдаемой последней точки к оценке итогового значения; над этой же календарной координатой — контурная полупрозрачная точка. Не создаётся фальшивый следующий месяц.
- График расширяет диапазон Y, чтобы прогноз не выходил за край SVG, не меняя фактических точек и их координат X.
- Маркер показывается лишь когда: прогноз доступен, его `horizon` равен периоду **последней отображённой** фактической точки, а `observedValue` точно совпадает с фактическим `value` этой точки. Для выбранного исторического месяца, пропущенного факта, отсутствующего/частичного прогноза либо иной детали маркер отсутствует.
- Под графиком приводятся по каждому активному ряду: прогноз, наблюдаемое значение, метод по компонентам, число исторических и проверочных месяцев, предупреждения об использовании фиксированной численности Drivers.
- В режимах операционных рядов **Д / Н / М** прогнозная точка не отображается: эти ряды — наблюдаемые INC и трудозатраты, не формулы ВБР/КТГ.

## Обзорная диаграмма и PDF

- Обзорная диаграмма **ВБР** использует прогноз **только из того же полного Report Snapshot**, если выбран последний месяц и фактическое значение в истории совпадает с `observedValue`. SLA и прочие графики остаются без нового прогноза.
- PDF `lineChart()` читает `snapshot.kpiView.cards.vbr.forecast`; при совпадении периода/факта рисует полупрозрачный контур и пунктир **внутри текущего месяца**. Подпись прямо указывает, что величина экспериментальная и не является фактом.
- Для PDF добавлен прогноз в детерминированный fingerprint, если он доступен; иначе существующая идентичность файла не меняется. `snapshot.results` и `executionTrace` не модифицируются.
- Обзор КТГ в PDF не добавляется как новый график в этом PR, поскольку текущий макет PDF содержит динамику ВБР/SLA/качества. КТГ продолжает иметь прогноз на карточке и в подробном SVG.

## Тесты

- `tests/test_kpi_chart_dialog_step7.js`: полупрозрачный контур, пунктир, сохранение двух настоящих точек, совпадение периода и наблюдаемого значения, отсутствие прогнозной линии при ошибке/несоответствии и в операционном режиме, обзорный ВБР.
- `tests/test_reliability_pdf.js`: fingerprint для PDF с прогнозом и неизменность исходного `KpiResult`, отсутствие отличий при недоступном прогнозе.
- `tests/test_step9_browser_offline.js`: реальный скомпилированный HTML, офлайн Chromium, ВБР и КТГ как независимые ряды со связанными forecast и фактическими компонентами; существующие сценарии PDF/SQLite.
- Полный CI с автономной HTML-сборкой обязателен перед слиянием в `main`.

## Ограничения

Исторический состав оборудования не измерен. Прогноз по компонентам использует фиксированное количество Drivers. Наблюдения за текущим днём могут быть неполными. Если ретропроверка/временной ряд не позволяют построить прогноз, реальный график остаётся обычным без пунктирной точки.
