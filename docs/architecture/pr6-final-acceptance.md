# PR-6 — Итоговая приёмка PR-1–PR-5

## Назначение

Итоговая проверка пяти технических изменений: подтверждённый отчётный период,
версионированные методы прогноза, единый Report Snapshot, SVG/паспорт/PDF
и общая диагностика качества классификации.

Приёмка не присваивает прогнозу официальный статус; модель по-прежнему
экспериментальная. Подтверждение границ реальных источников требует
экспортёра, который гарантирует полноту интервала; отсутствие в источнике
метаданных `meta.reportingCoverage` не устраняется косвенной датой события.

## Изменения в PDF по итогам аудита

В PDF общий показатель классификации теперь включает те же выбранные
`classificationCoverage`-счётчики и краткий агрегат групп инициаторов,
что и дашборд. В отпечаток отчёта включены **только** агрегированные
диагностические показатели и группы, без исходных строк и персональных
сведений. Изменение сверки ITSM/МБ меняет идентификатор PDF, даже если
сам процент качества не изменился. PDF не обращается напрямую к Dataset
и не выполняет повторную реклассификацию.

## Производительность: правила интерпретации

Новые измерения на синтетическом наборе являются sanity/performance
guard, а не утверждением об ускорении промышленного набора. Сравнение
времени запусков на разных GitHub runner не является достоверным
бенчмарком. Реальные значения из CI следует анализировать с учётом
изменений аппаратных ресурсов и масштабов данных. HTML в сборке имеет
ограничение 50 MiB; регрессия проверяет его отдельно. Избыточные
персональные строки в GitHub Actions не выводятся.

## Результат и оставшиеся ограничения

Приёмка считается успешной только если **все** этапы CI, в том числе
последний автономный Chromium, завершились `success`, и PR объединён в
`main`. Точные показатели времени и размера фиксируются в GitHub
Actions Job Summary, а не считаются неизменными характеристиками.

Методология не становится официальной и не подключается автоматически
к корпоративным источникам. Прогноз без подтверждённой полноты
источника останется недоступен, это не ошибка расчётной модели.
