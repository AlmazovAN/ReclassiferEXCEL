# RCA-PR28. Итоговая проверка второй очереди

| Критерии | Фактическая проверка |
|---|---|
| A01–A08 | Синтетический XLSX распознаётся по заголовкам. Проверены объединение PRB с локальными карточками, независимость локальных полей, отсутствие источника, дубли и неоднозначные связи ProblemGrade. Список из 231 записи в браузере остаётся проверить. |
| A09–A14 | Проверены требования к вердикту, единый черновик К/М, сохранность заполненного действия, покрытие, ЗНО и тип по умолчанию. Открытие редактора и красная отметка требуют проверки в браузере. |
| A15 | Сочетание Ctrl+Enter, положение фокуса и сохранность текста при ошибке требуют браузерной проверки. |
| A16–A20 | Проверены дедупликация, нулевые часы, границы периода, совпадение хеша и восстановление индекса после прерванной записи. |
| A21–A24 | Синтетическая библиотека содержит 9 сценариев и 74 шага. Проверены независимые копии, нулевая длительность, пересчёт и сохранность фактической даты. Редактор и исходная корпоративная книга требуют приёмки. |
| A25–A26 | Сквозной тест переносит расследование между виртуальными папками. Проверены оба статуса, проверка, ЗНО, график и содержимое отчёта. Снимки v1 и неизвестные поля читаются. Сохранение PDF требует браузерной проверки. |
| A27–A28 | Полный локальный verify прошёл. Автоматизированы проверки существующих Excel-процессов, V4, отказов записи и экспорта JSON. Проверка на реальной папке остаётся открытой. |

На 100 007 синтетических строк Worker обработал XLSX за 11,55 с. Наблюдавшийся максимум JS heap процесса Node — 480 МиБ, включая построение книги и тестовое окружение. Сравнимый по методике замер E3 на 10 007 строках составлял 1,25 с и 87 МиБ. PR13 фиксировал сборку и регрессию, замера памяти на этом этапе не было. Это измерение не характеризует память вкладки Edge/Chrome. Проверка подтверждает, что результат содержит три дневных строки и не включает номера INC.

Итоговый статус — автоматизированная регрессия пройдена. Ручная приёмка Windows/Edge/Chrome и подтверждение владельцем остаются открытыми.
