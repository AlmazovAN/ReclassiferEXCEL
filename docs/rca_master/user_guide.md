# RCA Master

1. Откройте `ReclassifierEXCEL.html`. Для прямой записи выберите рабочую папку на странице «Папки» и предоставьте браузеру доступ. В режиме импорта папки или без подключённой папки изменения остаются в памяти до экспорта.
2. Откройте «RCA Master», добавьте проблему и заполните паспорт. Номер PRB необязателен. Реестр ищет по номеру PRB или LOCAL, названию и оборудованию.
3. Добавьте симптомы и причины. «К» отмечает предполагаемую коренную причину, «М» требует мероприятия. Обе кнопки используют общий черновик. «Д» создаёт проверку. Для вердикта укажите проверяющего и результат осмотра. Для планирования или исполнения корректирующего мероприятия укажите ЗНО.
4. Откройте доказательство или мероприятие для редактирования в центральной области. Чтобы добавить фотографии, сначала сохраните карточку в папке с разрешением на запись и откройте её снова. Галерея принимает JPEG, PNG и WebP, до 20 файлов на карточку и до 20 МиБ на файл. Нажмите на миниатюру, чтобы увеличить фото. Снятие привязки оставляет оригинал в папке.
5. Для переноса откройте «Справочники» и выберите «Экспорт ZIP с фото». В другой рабочей папке с разрешением на запись выберите «Импорт JSON или ZIP», проверьте предпросмотр и подтвердите применение. Лимит ZIP — 192 МиБ, лимит JSON — 16 МиБ. JSON включает ссылки и метаданные.
6. В открытом расследовании выберите «Печать отчёта». Для расследования с фото можно выбрать перечень с подписями или перечень с первыми 12 миниатюрами. В диалоге браузера доступно сохранение в PDF.

## Вторая очередь

- Поместите официальный реестр ИТ-проблем и книгу типовых планов в `Catalogs/` и обновите справочники. Статус ITSM берётся из официального реестра. Статус PRB редактируется в паспорте. Начинайте расследование только для выбранных PRB.
- В паспорте нажмите «Обновить расчёты». Источник — итоговая книга `export_ITSM.xlsx`. Выберите 1, 3 или 6 месяцев. Пустой участок означает все участки, трудоёмкость отражает данные МБ.
- В сохранённой карточке мероприятия нажмите «Открыть типовой план», затем «Добавить типовой план». Меняйте сроки и шаги на экране графика. Нулевая длительность допустима. `Ctrl+Enter` отправляет форму на сохранение, а при ошибке форма остаётся открытой.

## Восстановление

После перезапуска снова подключите ту же рабочую папку. При повреждении индекса приложение сообщает о затронутых файлах и читает предыдущее валидное поколение, если оно доступно. При повреждении снимка попробуйте открыть карточку и проверьте показанную ревизию. Сохраните копию всего каталога `RCA/` перед ручным восстановлением. Перенос через архив сохраняет пользовательские поля и связи. Формат хранения описан в [ADR PR-02](pr02_json_storage.md).

Режим импорта папки предоставляет чтение. Перед сменой папки или закрытием вкладки выгрузите изменения в JSON. Для пользовательских материалов в архив включаются ссылки и метаданные.
