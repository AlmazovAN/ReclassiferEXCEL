# Технические требования RCA Master v3

Этот документ фиксирует действующий контракт второй очереди в репозитории. Исторические документы описывают исходный MVP.

| Область | Контракт |
|---|---|
| Официальные PRB | Нормализация по заголовкам, диагностика конфликтов, версии с хешем источника, отдельные локальный и официальный статусы. |
| Паспорт и причины | Ручные поля и цепочки сохраняются. ProblemGrade даёт связи, официальный реестр даёт реквизиты. Оценка узла выводится из проверок с фактическим результатом и ответственным. |
| Мероприятия | Общий черновик К/М, ЗНО для планирования и исполнения корректирующих действий, отчёт для завершения. |
| Расчёты | Worker читает итоговую книгу, дедуплицирует INC и публикует дневной индекс. Периоды 1, 3 и 6 месяцев вычисляются по индексу. |
| Типовые планы | Девять сценариев, независимые экземпляры в мероприятиях, календарные дни с поддержкой нулевой длительности, отдельные фактические даты. |
| Обмен | Архив сохраняет карточку v1, снимок официальных реквизитов и экземпляры планов. Печать строится из выбранной карточки. |

Подробные правила и ограничения приведены в документах этапов E1–E4 в этой папке. Публикация проверяется локальным `tools/local-ci.ps1 verify`.
