# E1. Официальный реестр ИТ-проблем

Поместите исходную книгу в `Catalogs/`, подключите рабочую папку и нажмите «Обновить справочники». Worker распознаёт реестр по заголовкам «Номер», «Статус» и «Краткое описание». Разные строки с одним PRB исключаются из результата с диагностикой. Совпадающие дубли дают одну запись. Отсутствие официального реестра само по себе не блокирует ITSM/МБ.

RCA Master показывает официальный статус ITSM, проект и остальные реквизиты отдельно от рабочего паспорта. Нажмите «Начать расследование», чтобы создать карточку конкретного PRB. Ранее созданную локальную карточку можно связать с PRB через редактирование паспорта. У неё сохраняются UUID и связи. Если PRB исчез из официального реестра, расследование остаётся в списке с пометкой о недоступности официальной записи.

В режиме прямой записи версия реестра сохраняется в `RCA/references/it-problems/`. Снимок v1 содержит нормализованные записи, хеш источника, имя файла, время загрузки, число прочитанных строк и предупреждения. Контрольная сумма защищает снимок при повторном открытии. При повреждении последнего файла читается предыдущий валидный. Повторное чтение книги с тем же хешем не создаёт новое поколение. В режиме импорта папки можно читать сохранённый снимок или обновлять данные в памяти и выгружать JSON.

ProblemGrade по-прежнему связывает PRB с четырьмя уровнями классификации. Название и статус берутся из официального реестра. Неоднозначность ProblemGrade обрабатывается действующим конвейером.

Приёмочные данные синтетические. Старые индексы расследований читаются без миграции. Поля участка и проекта попадают в поисковую проекцию после следующего сохранения соответствующей карточки.
