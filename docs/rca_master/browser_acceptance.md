# Браузерная приёмка RCA Master

Используйте отдельную рабочую папку и синтетические расследования. Автоматическую проверку запускайте через `tools/local-ci.ps1 verify`.

| Сценарий | Ожидаемый результат |
| --- | --- |
| Открыть доказательство из списка и из дерева, изменить поле, вернуться клавиатурой | Видна карточка нужной записи. При выходе с изменениями отображается подтверждение. После отмены выхода значения остаются в форме. |
| Открыть график из мероприятия, поменять порядок и срок шага, вернуться | Открывается то же мероприятие. Повторное открытие графика показывает сохранённые шаги. Длительность 0 допустима. |
| Добавить несколько фото с подписью, увеличить фото, снять одну привязку и перезапустить приложение | Оставшиеся фото и подписи доступны. Снятая привязка отсутствует в карточке. |
| Перенести ZIP в чистую рабочую папку и повторить импорт | В предпросмотре видны фото и размеры. Повторный импорт показывает совпадение. |
| Открыть отчёт в обоих режимах печати | Подписи относятся к нужным карточкам. Во втором режиме не более 12 миниатюр. Доступно сохранение в PDF. |
| Открыть RCA при увеличении 125%, 150%, 200% и на узком экране | Доступны поля и кнопки. Широкие дерево и график прокручиваются в своих областях. |
| Проверить реестр на 1, 100 и 500 записях, многократно открыть и закрыть галерею | Поиск и переходы остаются доступны. После выхода из галереи временные адреса изображений освобождаются. |
