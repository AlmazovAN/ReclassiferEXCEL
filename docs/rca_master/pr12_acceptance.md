# PR-12. Локальная приёмка RCA Master

Статус «частично» означает, что автоматизированная проверка модели или сборки пройдена, а пользовательское действие в браузере ещё требует проверки.

| Критерии | Результат | Проверка |
|---|---|---|
| ACC-01–04 | Частично | Тест собранного HTML и 20 переключений в тестовом DOM |
| ACC-05–10 | Частично | Пустой индекс, права, прерывание записи, UUID, дубли PRB и поиск |
| ACC-11 | Частично | Поиск по 500 строкам. Положение кнопки и прокрутка требуют браузера |
| ACC-12–17 | Частично | Сохранение паспорта и дерева, родительские связи, циклы и флаг К. Вкладки, линии и масштаб требуют браузера |
| ACC-18–28 | Частично | Создание и защита заготовок, конфликт вердиктов, семь секторов, множественные связи и покрытие. Диалоги требуют браузера |
| ACC-29–31 | Частично | Пустые словари и сохранение значений. Модальное окно, Esc, фокус и подсказки требуют браузера |
| ACC-32–36 | Частично | JSON round-trip, повторный импорт, ошибки формата и ссылок, предупреждение о приложениях. Выбор файла и предпросмотр требуют браузера |
| ACC-37–38 | Частично | Содержимое печатной формы проверено в тестовом DOM. Печать и PDF требуют браузера |
| ACC-39 | Частично | Сквозной сценарий с синтетическим RCA без ITSM/МБ |
| ACC-40 | Вне текущего объёма | Необязательный PR-11 |
| ACC-41 | Пройден | Полный `tools/local-ci.ps1 verify` |
| ACC-42 | Пройден | Проверены рабочее дерево и наличие целевого HTML в игнорируемом `dist/` |
| ACC-43 | Частично | Тесты существующих Excel-процессов и V4 прошли. Сквозной браузерный переход требует проверки |
| ACC-44–45 | Частично | Два изолированных пространства и повторное открытие JSON проверены на виртуальной файловой системе. Смена реальной папки и перезапуск браузера требуют проверки |

Edge запустился в режиме автоматизации, но соединение с его локальным портом вернуло `EACCES`. Попытка подключения через отладочный канал без сети также не дала ответа. Браузерные критерии остаются открытыми.
