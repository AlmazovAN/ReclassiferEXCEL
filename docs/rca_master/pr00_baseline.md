# PR-00. Исходное состояние ReclassifierEXCEL

- Ветка `main`, коммит `1a09f90`, чистое рабочее дерево перед изменениями.
- Python 3.15.0, Node.js 24.22.0.
- `tools/local-ci.ps1 verify` успешно выполнил контроль 50 зависимостей Worker, сборку, 6 тестов Папок и 12 проверок V4. V4-12 прошёл.
- Целевой файл `dist/ReclassifierEXCEL.html` собирает `build/build_folders.py`. Интерфейсные стили и скрипты встраиваются через маркеры STYLE и SCRIPT. `src/folders/engine-files.json` перечисляет модули Worker.
- Штатная навигация использует `[data-page]` в `folders.js`. Основное меню находится в единственном `aside.sidebar`.
- В режиме выбора папки UI запрашивает `showDirectoryPicker({ mode: 'readwrite' })`. Режим импорта через `webkitdirectory` предоставляет файлы для чтения. Для RCA потребуется явно отражать доступность сохранения при каждом подключении.
- `Start_Reclassifier.cmd` запускает поставляемый локальный обработчик по адресу `http://127.0.0.1:8765/`. При прямом открытии HTML режим `file:` распознаётся интерфейсом.

Доступность файловых API и выдача разрешений в реальном браузере на исходной сборке остаются непроверенными.
