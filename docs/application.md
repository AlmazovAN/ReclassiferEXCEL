# Назначение ReclassifierEXCEL

ReclassifierEXCEL — локальное приложение для накопительного обновления ITSM и МБ, чтения справочников, реклассификации заявок и подготовки данных надёжности. Работает в браузере с Excel-файлами выбранной папки.

## Типовой процесс

1. Пользователь выбирает рабочую папку `Catalogs/ITSM/MB`.
2. Команда «Обновить справочники» распознаёт, проверяет и нормализует источники.
3. Команда «Обновить выгрузки» готовит инкрементальное обновление `export_ITSM.xlsx` и `export_MB.xlsx`.
4. Приложение показывает изменения, ошибки, источник и статус.
5. Пользователь сохраняет подготовленные книги напрямую либо скачивает их для замены.
6. При необходимости запускается реклассификация и экспорт диагностики.

Обработка больших объёмов организована через Web Worker. Реальные корпоративные источники остаются за пределами GitHub.

## Развитие

Новые предметные интерфейсы (в частности, RCA Master) используют действующую оболочку и читают нормализованные данные по проверенным контрактам. Приоритет — сохранение совместимости накопительных книг и ограничение пикового использования памяти.
