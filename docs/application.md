# Описание Reclassifier

Reclassifier помогает специалистам сопровождения обновлять накопительные данные ITSM и Мобильных бригад, проверять классификацию заявок и рассчитывать показатели надёжности оборудования. Приложение запускается локально из HTML-файла. Исходные выгрузки, справочники и результаты остаются на компьютере пользователя.

## Регулярное обновление выгрузок

Сборка «Папки» работает с общей папкой, в которой `Catalogs` содержит справочники, а `ITSM` и `MB` содержат книги соответствующих источников. Сначала приложение обновляет семь расчётных справочников. Затем оно обрабатывает новые выгрузки, обновляет накопительные книги и показывает периоды данных. При подключении папки для записи приложение может записывать результаты напрямую. При импорте пользователь сохраняет или скачивает обе итоговые книги вручную. Журнал помогает установить этап сбоя при чтении, обработке или записи.

## Реклассификация и отчётность

В сборке CORE можно проверить исходную классификацию заявок ITSM, изучить основания предложенных изменений и применить их к справочнику ReClass. Следующий расчёт ITSM использует актуальный ReClass. Справочники и каталоги оборудования дополняют данные заявок. При наличии набора Мобильных бригад приложение сопоставляет заявки с задачами и заполняет связанные поля. Доступность показателей в отчёте зависит от состава и полноты загруженных наборов.

CORE поддерживает подключение существующей базы `Reclassifier.db` для ведения рабочих наборов. Для переноса результатов можно сохранить обновлённую базу или создать переносимый HTML-снимок. Отчёт по надёжности показывает KPI, динамику, прогнозы и паспорта расчётов и поддерживает экспорт в PDF.
