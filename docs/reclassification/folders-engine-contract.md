# Контракт реклассификации в ReclassifierEXCEL.html

## Движок и адаптер

Бизнес-логика строит контекст справочников один раз на запуск через `buildContext` и обрабатывает заявки через `evaluateRow`. Для независимой версии вход расчёта состоит из исходных фактов заявки и нормализованного классификатора. Результат содержит предложенный путь, основания, статус и сведения для ручной проверки. Инженерную разметку присоединяет модуль сравнения после расчёта.

Адаптер связывает движок с приложением. Реестр сборки «Папки» выбирает адаптер по идентификатору из `src/folders/reclassification/registry.js`. Для адаптера обязательны `id`, `version` и асинхронный метод `run(input, onProgress)`.

- `input.source` — выбранный файл ITSM. `input.classifier` — нормализованные записи, метаданные и результат проверки классификатора. `input.references` — подготовленные справочники для совместимости с текущим V3. `input.asOfDate` — дата расчёта.
- Прогресс передаётся объектом `{label, percent}`.
- Результат содержит `bytes` как передаваемый Worker буфер `ArrayBuffer`, `outputName` и `stats` с `rows` и `readyRows`. Сценарий добавляет `engineId` и `engineVersion`. Запись в рабочую папку не входит в этот сценарий.

## Подключение версии

1. Добавить адаптер и его зависимости в сборку и зарегистрировать адаптер в реестре «Папок».
2. Проверить обработку книги и содержимое диагностики для новой версии. Для независимой версии дополнительно изменить инженерную разметку в тесте и убедиться, что решение движка осталось прежним.
3. Выставить нужный `activeFolderReclassificationEngineId` и пересобрать HTML. Для возврата выбрать прежний идентификатор.

Активен `independent-4.0` (4.0.0-dev). Он запускает каскад V4 на исходных фактах, формирует отдельную книгу диагностики и присоединяет инженерную классификацию из ReClassification только для сравнения. Полный путь V4 считается кандидатом на инженерную проверку. `readyRows` для V4 равен нулю.

Адаптер `legacy-3.3` (3.3.0) остаётся в реестре с прежним диагностическим отчётом и режимом `standard`. Переключение на неизвестный идентификатор даёт ошибку.

Для отката в `registry.js` замените значение `activeFolderReclassificationEngineId` на `legacy-3.3` и выполните `python build/build_folders.py`. Чтобы вернуть V4, выберите `independent-4.0` и повторите сборку. Быстрый набор проверяет оба переключения на одной книге и ошибку при неизвестном идентификаторе.
