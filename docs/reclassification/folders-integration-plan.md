# План подключения реклассификации в ReclassifierEXCEL.html

1. **Зафиксировать входные данные и ожидаемый результат.** Проверить контракт существующего обработчика на обезличенных выгрузках. Определить, какую книгу ITSM берёт кнопка в первой версии, какие колонки и справочники обязательны и какую версию правил запускаем. Проверить передачу исходного текста из колонки V. Подготовленный результат ITSM может уже содержать объединённый текст V и W, поэтому эти два источника нельзя считать взаимозаменяемыми.
2. **Подключить существующий расчёт к Worker сборки «Папки».** Подключить зависимости через сборку и добавить сообщение запуска. Адаптер должен передавать файлы, справочники и параметры, получать прогресс и результат. Повторно использовать действующие правила и формат отчёта. Перед запуском проверять входы и блокировать параллельное обновление выгрузок.
3. **Выпустить первый сценарий с предварительным просмотром.** После нажатия показать источник и готовность справочников, затем запустить расчёт. Показать количество обработанных строк, предложений и записей для ручной проверки. Дать скачать диагностический Excel отдельно. Ошибку и отмену отображать в карточке и журнале, после них разрешать повторный запуск.
4. **Добавить применение отдельным шагом.** Показать, какие изменения попадут в ReClass. Перед подтверждением проверить, что справочник и исходная книга совпадают с использованными при расчёте. После подтверждения сохранить результат с учётом режима работы с папкой. Для предложений V4 сохранить существующие ограничения инженерной проверки. После обновления ReClass запускать обновление выгрузок отдельным действием пользователя.
5. **Проверить перед включением.** Сравнить результаты с эталоном действующего обработчика. Проверить отсутствие входного файла, несовместимые колонки, блокировку книги Excel, отмену, повторный запуск, большой файл и работу через импорт. Повторить проверки обновления справочников, ITSM и МБ.

В текущей сборке кнопка принимает исходную книгу ITSM, использует классификатор из Catalogs и обновлённые справочники, показывает число обработанных строк и сохраняет диагностическую книгу по запросу. Следующий этап — проверка предложений и подтверждаемая запись в ReClass.
