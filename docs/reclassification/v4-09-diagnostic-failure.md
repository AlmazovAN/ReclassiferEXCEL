# V4-09 — третий уровень: неисправность

Выбор канонической неисправности производится только по явному диагностическому маркеру дефекта, привязанному V4-07 к отказавшему объекту V4-08, и по активной допустимой ветке V4-04. Нельзя подставлять единственную неисправность из справочника без диагностического доказательства. Используются только прямые названия и ограниченные падежные варианты (`Обрыв`, `Отказ`, `Повреждение`, `Короткое замыкание`); синонимы без согласования не добавляются.

Статусы: `SELECTED`, `UNRESOLVED`, `BLOCKED_BY_ELEMENT`, `INVALID_PREFIX`, `AMBIGUOUS_FAILURE`, `NOT_APPLICABLE`. Сохраняются исходные поле, текст и смещения маркера. Результат неизменяем, `candidatePath=[equipment,element,failure,null]`, `readyForApply=false`. Не используются первичная/инженерная классификации, legacy 3.3, комментарии МБ. Четвёртый уровень не назначается. Полная пользовательская приёмка на реальных обращениях не заявлена.
