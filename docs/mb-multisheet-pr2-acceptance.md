# PR-2 — приёмка многолистовой загрузки МБ (ЗФ/КФ)

## Область проверки
Проверяется **импорт одного XLSX с двумя рабочими листами**, их независимое сопоставление по заголовкам, сохранение всех принятых строк в Worker Dataset и в экспортном XLSX. Аналитические правила не меняются.

### Эталон по предоставленному образцу
- ПСПА ЗФ — 19 436 строк данных, 63 колонки.
- ПСПА КФ — 1 667 строк данных, 52 колонки.
- Всего — 21 103 строк данных (без строки заголовка каждого листа).
- На этапе чтения отклонения должны объясняться пустыми строками или правилами `hasSourceData`; 21 103 строк ожидается только при наличии содержимого во всех строках.
- Количество уникальных строк после UPSERT проверяется отдельно и не обязано равняться количеству входных строк.

## Автоматические проверки
```bash
node tests/test_mobile_brigade_multisheet.js
node tests/test_mobile_brigade_zf_kf_21k.js
node tests/test_mobile_brigade_worker_processor.js
python build/build.py --core
```
Новый тест генерирует **синтетические данные** с 19 436 строками ЗФ и 1 667 строками КФ, с 63 и 52 заголовками соответственно. Проверяются оба порядка листов, необязательный служебный лист, незавершённые задачи, баланс `sheetDetails`, количество записей в обоих Dataset, уникальность ключей и количество строк выгружаемого XLSX. Данные реального файла в GitHub не публикуются.

## Обязательная приёмка реальным файлом (вручную)
1. На ветке PR-1/PR-2 собрать HTML, проверить, что это именно новая версия, а не ранее сохранённый HTML.
2. Импортировать пользовательский файл `tasks_2026-09-01_2026-10-20 (1) все.xlsx` через интерфейс Мобильных бригад.
3. Сверить журнал: оба листа распознаны, по каждому есть `inputRows`, `acceptedRows`, `skippedRows`. Все пропущенные листы отражены в предупреждениях.
4. Проверить отдельные этапы: Worker → кандидат Mobile Brigade Data → Full Dataset → UPSERT после применения. Сохранить значения итоговых счётчиков.
5. Проверить повторную загрузку того же файла без непредусмотренного прироста.
6. Проверить однолистовый Excel как регрессию.
7. При расхождении эталона зафиксировать причину и блокировать merge.
