# Reclassifier 0.36.4 — исправление загрузки Mobile Brigade

## Исправлено
- Устранена блокировка кнопки загрузки/применения при повторяющихся `recordKey` во входной выгрузке МБ.
- Предварительный анализатор `database_recognizer.js` теперь сообщает о повторах как о предупреждении, а не об ошибке.
- Существующий обработчик из версии 0.36.3 сохраняет первую запись без изменений и добавляет `-D1`, `-D2` и далее для последующих совпадений.
- Критические ошибки (например, отсутствие устойчивого идентификатора) по-прежнему блокируют импорт; контроль повторов ITSM не изменён.

## Приёмка в Codespaces
```bash
node tests/test_database_recognizer.js
node tests/test_mobile_brigade_duplicate_recordkeys.js

node tests/test_mobile_brigade_multisheet.js
python build/build.py --core
```
