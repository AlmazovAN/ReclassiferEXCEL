# Reclassifier 0.36.3

## Изменения

- Сохранение всех записей с повторяющимися recordKey.
- Первое вхождение сохраняет исходный идентификатор.
- Повторные строки получают суффиксы -D1, -D2 и далее.
- Предупреждение о количестве повторов.
- Защита от конфликтов идентификаторов.
- Сохранение совместимости с накопительным UPSERT.

## Проверка

Регрессионные тесты Mobile Brigade выполнены
перед сборкой релиза.
