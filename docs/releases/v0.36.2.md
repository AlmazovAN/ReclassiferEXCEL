# Релиз 0.36.2

Дата оформления: 2026-10-20.

## Изменения

- Модуль «Мобильные бригады»: один Excel-файл может содержать несколько листов с данными, которые объединяются в общую обработанную таблицу.
- Подходящие листы определяются по обязательным заголовкам, без привязки к названию листа и порядку столбцов.
- Новые/неизвестные колонки не блокируют обработку, но выводятся в журнале как предупреждение; повторяющиеся названия колонок блокируют обработку во избежание потери данных.
- Сохранена действующая схема вывода 38 колонок, Mobile Brigade Data, Full Dataset и UPSERT по recordKey, включая незавершённые задачи без фактической даты.
- Добавлен тест `tests/test_mobile_brigade_multisheet.js` на два листа, произвольный порядок колонок, незнакомую колонку и незавершённую задачу.

## Проверка

В GitHub Codespaces пользователь успешно запустил:
- `node tests/test_mobile_brigade_multisheet.js`
- `node tests/test_mobile_brigade_worker_processor.js`
- `node tests/test_mobile_brigade_upsert.js`

Все три теста завершились успешно. Полная регрессионная проверка, сборки CORE/FULL и испытание на полном рабочем XLSX не подтверждены.

## Сборка

```bash
python build/build.py --core
```

Ожидаемые имена выходных файлов при штатном сборщике:
- `dist/Reclassifier_v0.36.2_CORE.html`

Номер приложения задаёт файл `VERSION`; при наличии переменной `RECLASSIFIER_VERSION` она может переопределить его.
