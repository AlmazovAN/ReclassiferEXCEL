# Browser module components

Предметные модули отделены от общей оболочки. Все они работают автономно в браузере без сетевых обращений.

- `reclassification/` — конфигурация, UI, базовые правила перекладки десяти полей ITSM и Worker. Полная реклассификация с дополнительными справочниками остаётся отдельным направлением развития.
- `itsm/` — конфигурация, схема 51-полевого Dataset, UI/Worker и проверенные правила; обработка в SQLite использует `datasetOnly` без ненужной XLSX-сериализации.
- `mobile_brigade/` — конфигурация, UI, правила, обработчик выгрузок и UPSERT по устойчивому ключу.
- `equipment/` — конфигурация, состояние, нормализация и объединение каталогов, менеджер жизненного цикла и UI.
- `failure_classifier/` — нормализация, жизненный цикл и UI классификатора отказов.

Общий каталог `src/js/app/` содержит маршрутизацию, общие представления, раздел БД, SQLite-first Runtime Repository, legacy HTML Dataset Pipeline и вспомогательные механизмы сборки снимка.

**Граница данных:** когда `Reclassifier.db` открыта, SQLite — единственный источник сохраняемых Dataset, а HTML-снимок недоступен. Без открытой БД доступен автономный HTML-режим и сохранение его применённых наборов. Предметные правила и DOM-рендеринг отдельных модулей не нужно переносить в общую оболочку.
