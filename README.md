# Reclassifier

Reclassifier — автономное браузерное приложение для локальной обработки Excel-выгрузок ITSM и Мобильных бригад, ведения рабочих справочников и анализа надёжности оборудования.

Текущая версия приложения: **0.38.0**.

Приложение не отправляет рабочие данные в сеть. Пользователь открывает один HTML-файл, подключает свою `Reclassifier.db` и выбирает Excel-файлы на компьютере. Бизнес-данные не хранятся в репозитории и не включаются в CORE-сборку.

## Быстрый старт

1. Откройте `Reclassifier_vX.Y.Z_CORE.html` в поддерживаемом браузере.
2. Если у вас есть `Reclassifier.db`, откройте её в разделе **База данных**. CORE не создаёт пустую SQLite: без существующей базы можно работать с наборами в текущей вкладке и сохранить переносимый HTML с данными.
3. Загрузите справочники, каталоги оборудования и классификатор отказов. С подключённой SQLite делайте это через раздел базы; без неё — через соответствующие разделы приложения.
4. Если доступны актуальные выгрузки **Мобильных бригад**, обработайте и примените их. Без набора МБ ITSM продолжит обработку, но не заполнит связанные поля обогащения.
5. При необходимости обновить классификацию запустите **Реклассификацию**, проверьте диагностику и примените подготовленные изменения в ReClass.
6. Запустите **ITSM** для обогащения заявок актуальными данными и накопления Dataset.
7. Откройте **Отчёт по надёжности**. Доступность показателей зависит от состава и полноты подключённых Dataset.

SQLite является источником истины, пока она открыта. Подтверждённый COMMIT меняет рабочую базу браузера; для записи в исходный файл используйте прямое сохранение с проверкой либо скачайте обновлённую SQLite. При необходимости можно сохранить переносимый HTML-снимок. Сохранение SQLite и HTML-снимка — разные операции.

## Функциональные блоки

- **Реклассификация** — диагностика штатной классификации ITSM, просмотр оснований и подготовка обновления ReClass.
- **ITSM** — расчёт дополнительных полей, обогащение по справочникам и Мобильным бригадам, выгрузка Excel и обновление накопительного ITSM Dataset.
- **Мобильные бригады** — объединение нескольких Excel, расчёт полей и накопительное обновление задач по устойчивому ключу.
- **Справочники** — загрузка и проверка ReClass, Drivers, Customers, TypeRequest, Initiators, Exceptions и ProblemGrade.
- **Оборудование** — управление пятью исходными каталогами и пересчёт производного `Equipment_Combined`.
- **Классификатор отказов** — загрузка поддерживаемых форматов, фильтрация области сопровождения и публикация рабочего справочника.
- **Отчёт по надёжности** — KPI, паспорта расчётов, динамика, прогнозы и PDF на основе доступных источников.
- **База данных** — импорт и аудит Dataset, перепроверка целостности, сохранение, экспорт и восстановление SQLite.

## Как связаны данные

```text
Справочники + Equipment ─────────────┐
                                     ├─> обработка ITSM ─> ITSM Dataset ─┐
Мобильные бригады ─> Dataset МБ ─────┘                                  ├─> KPI / отчёт / PDF
Реклассификация ─> обновление ReClass ──────────────────────────────────┘
```

Мобильные бригады — дополнительный источник для сопоставления заявок, трудозатрат и KPI. Если этот Dataset не загружен, обработка ITSM всё равно выполняется, но связанные значения остаются пустыми и наличие заявки отмечается как неизвестное. Реклассификация — отдельный шаг контроля классификации и обновления ReClass; обработка ITSM использует актуальный ReClass при следующем расчёте. В отчёт попадают только показатели, для которых доступны необходимые источники.

```powershell
python build/build.py
powershell -NoProfile -ExecutionPolicy Bypass -File tools/local-ci.ps1 verify -IncludeBrowser
```

GitHub выполняет быстрый PR-suite; полный build workflow запускается вручную. Публикация релиза — отдельная явная операция.
