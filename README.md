# Reclassifier

Reclassifier — автономное браузерное приложение для локальной работы с Excel-выгрузками ITSM и Мобильных бригад (МБ), реклассификации заявок и анализа надёжности оборудования.

Текущая версия приложения: **0.38.0**. Бизнес-данные обрабатываются на компьютере пользователя. Исходные книги, рабочая SQLite и результаты выгрузок хранятся отдельно от исходного кода.

| Сборка | Когда использовать | Как собрать |
| --- | --- | --- |
| **Папки** | Обновить расчётные справочники и накопительные книги ITSM и МБ в общей папке | `py build/build_folders.py` → `dist/ReclassifierEXCEL.html` |
| **CORE** | Проверить классификацию, обновить ReClass, вести рабочие наборы в SQLite и строить отчёты по надёжности | `python build/build.py` → `dist/Reclassifier_vX.Y.Z_CORE.html` |

[Назначение приложения, входные данные и результаты](docs/application.md)

## Быстрый старт «Папки»

1. Откройте `dist/ReclassifierEXCEL.html` в Edge или Chrome.
2. Подготовьте общую рабочую папку с подпапками `Catalogs`, `ITSM` и `MB`.
3. Нажмите **Подключить папку для записи**, чтобы предоставить браузеру доступ к рабочей папке. Если такой доступ недоступен, нажмите **Выбрать папку для импорта**.
4. Нажмите **Обновить справочники**, затем **Обновить выгрузки**.
5. В режиме импорта сохраните обе итоговые книги через **Сохранить ITSM** и **Сохранить MB**. Если браузер отклоняет сохранение, скачайте книги и замените их в соответствующих подпапках через Проводник.

Для восстановления прерванной записи откройте ту же рабочую папку в том же браузере, профиле и режиме запуска. `Start_Reclassifier.cmd` можно использовать для запуска с замером памяти браузера. При диагностике включите нужные категории на странице **Журнал**.

При импорте совместимых книг МБ временные строки потоковой обработки сжимаются в памяти без запроса доступа к OPFS. Лимит для сжатого буфера — 256 МиБ. Для готовых книг действует отдельный лимит 256 МиБ. Журнал импорта и экспорта показывает размеры до и после сжатия. **Расширенная диагностика** регистрирует режим, этап ошибки и число вызовов чтения по подпапкам.

Для проверки потокового обновления МБ добавьте `#mb=stream` в конец адреса открытого HTML-файла
на копиях книг. В этом режиме накопленная МБ читается порциями, а в памяти
остаются компактный индекс и полные строки затронутых задач. Для изменённых в
Excel книг и некоторых старых форматов приложение сообщает о переходе на
обычную обработку. Без параметра адреса используется обычный режим.

Сборка готовит семь справочников расчёта, обновляет пару ITSM и МБ и отображает их
периоды. Сборка CORE описана ниже и использует отдельную точку входа `build/build.py`.

## Реклассификация в «Папках»

Поместите один классификатор отказов в `Catalogs` и нажмите **Обновить справочники**. Укажите период по дате выполнения и нажмите **Реклассификация**. Приложение использует `export_ITSM.xlsx` из рабочей папки или свежую книгу, подготовленную в режиме импорта. Обе границы включаются в период. Пустая граница оставляет соответствующую сторону открытой. После расчёта нажмите **Скачать диагностику Excel**. Итоговая книга содержит диагностику и сводку. На этом этапе приложение сохраняет результат отдельным файлом по запросу пользователя.

[План дальнейшего подключения к рабочему процессу](docs/reclassification/folders-integration-plan.md)

## Быстрый старт CORE

1. Откройте `Reclassifier_vX.Y.Z_CORE.html` в поддерживаемом браузере.
2. Если у вас есть `Reclassifier.db`, откройте её в разделе **База данных**. CORE не создаёт пустую SQLite: без существующей базы можно работать с наборами в текущей вкладке и сохранить переносимый HTML с данными.
3. Загрузите справочники, каталоги оборудования и классификатор отказов. С подключённой SQLite делайте это через раздел базы; без неё — через соответствующие разделы приложения.
4. Если доступны актуальные выгрузки **Мобильных бригад**, обработайте и примените их. Без набора МБ ITSM продолжит обработку, но не заполнит связанные поля обогащения.
5. При необходимости обновить классификацию запустите **Реклассификацию**, проверьте диагностику и примените подготовленные изменения в ReClass.
6. Запустите **ITSM** для обогащения заявок актуальными данными и накопления Dataset.
7. Откройте **Отчёт по надёжности**. Доступность показателей зависит от состава и полноты подключённых Dataset.

SQLite является источником истины, пока она открыта. Подтверждённый COMMIT меняет рабочую базу браузера; для записи в исходный файл используйте прямое сохранение с проверкой либо скачайте обновлённую SQLite. При необходимости можно сохранить переносимый HTML-снимок. Сохранение SQLite и HTML-снимка — разные операции.

## Функциональные блоки

- **Реклассификация** — диагностика штатной классификации ITSM, просмотр оснований и подготовка обновления ReClass.
- **ITSM** — расчёт дополнительных полей, обогащение по справочникам и Мобильным бригадам, выгрузка Excel и обновление накопительного ITSM Dataset.
- **Мобильные бригады** — объединение нескольких Excel, расчёт полей и накопительное обновление задач по устойчивому ключу.
- **Справочники** — загрузка и проверка ReClass, Drivers, Customers, TypeRequest, Initiators, Exceptions и ProblemGrade.
- **Оборудование** — управление пятью исходными каталогами и пересчёт производного `Equipment_Combined`.
- **Классификатор отказов** — загрузка поддерживаемых форматов, фильтрация области сопровождения и публикация рабочего справочника.
- **Отчёт по надёжности** — KPI, паспорта расчётов, динамика, прогнозы и PDF на основе доступных источников.
- **База данных** — импорт и аудит Dataset, перепроверка целостности, сохранение, экспорт и восстановление SQLite.

## Как связаны данные

```text
Справочники + Equipment ─────────────┐
                                     ├─> обработка ITSM ─> ITSM Dataset ─┐
Мобильные бригады ─> Dataset МБ ─────┘                                  ├─> KPI / отчёт / PDF
Реклассификация ─> обновление ReClass ──────────────────────────────────┘
```

Мобильные бригады — дополнительный источник для сопоставления заявок, трудозатрат и KPI. Если этот Dataset не загружен, обработка ITSM всё равно выполняется, но связанные значения остаются пустыми и наличие заявки отмечается как неизвестное. Реклассификация — отдельный шаг контроля классификации и обновления ReClass; обработка ITSM использует актуальный ReClass при следующем расчёте. В отчёт попадают только показатели, для которых доступны необходимые источники.

```powershell
python build/build.py
powershell -NoProfile -ExecutionPolicy Bypass -File tools/local-ci.ps1 verify -IncludeBrowser
```
