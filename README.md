# ReclassifierEXCEL

Автономное локальное приложение для обработки Excel-выгрузок ITSM и «Мобильных бригад» (МБ), нормализации справочников, реклассификации обращений и ведения связанных данных надёжности.

**Единственная целевая сборка:** `ReclassifierEXCEL.html`, формируется из `src/folders/` командой `python build/build_folders.py`. Работа выполняется в браузере с файлами на компьютере пользователя. Серверная БД и встроенная БД не входят в архитектуру продукта.

## Начало работы

1. Сборка: `python build/build_folders.py`.
2. Запуск: открыть `dist/ReclassifierEXCEL.html` в поддерживаемом браузере или запустить `dist/Start_Reclassifier.cmd`.
3. Подготовить рабочую папку с `Catalogs`, `ITSM`, `MB`.
4. Выбрать папку для записи или импорта, затем нажать «Обновить справочники».
5. Нажать «Обновить выгрузки». При необходимости выполнить реклассификацию и сохранить диагностический Excel.

Итоговые накопительные книги: `ITSM/export_ITSM.xlsx` и `MB/export_MB.xlsx`. Исходные книги и корпоративные справочники **не хранятся в GitHub**.

## Исходный код

- `src/folders/index.html` — основная оболочка и меню.
- `src/folders/folders.js` — интерфейс, маршруты и действия.
- `src/folders/folders.css` — стили.
- `src/folders/engine-files.json` — **исчерпывающий список** зависимостей Worker.
- `src/folders/engine/` — логика работы с Excel, справочниками и данными.
- `src/folders/reclassification/` — версии и адаптеры реклассификации.
- `src/js/` — только общие функции и обработчики, реально подключаемые действующей сборкой.
- `build/build_folders.py` — сборщик автономного HTML.
- `tests/test_folders*.cjs` и выбранные тесты V4 — действующие регрессии.

Подробности: [ARCHITECTURE.md](ARCHITECTURE.md), [docs/application.md](docs/application.md), [tools/LOCAL-CI.md](tools/LOCAL-CI.md), [AGENTS.md](AGENTS.md).

## Проверка перед изменениями и публикацией

Выполнять **локально** на рабочем ПК:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/local-ci.ps1 verify
```

Локальные тесты не должны обращаться к корпоративным рабочим книгам — только обезличенные и синтетические данные.

GitHub используется для периодической синхронизации **только по явному запросу пользователя**. Никакие push, релизы, PR или GitHub Actions не запускаются автоматически.

## Дальнейшее развитие

Новые модули (например, RCA Master) подключаются к `src/folders/` и его существующей навигации. Нельзя строить параллельное приложение, новую БД или копию процесса обработки ITSM/МБ без самостоятельного утверждённого решения.
